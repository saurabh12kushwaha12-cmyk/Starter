# Reviewer Playbook
1. Install using the submitted README without participant help.
2. Start mock services and reviewer mode.
3. Run automated tests.
4. Execute SCN-001 through SCN-008.
5. Verify customer isolation, confirmation, and duplicate prevention.
6. Trigger expired auth, legacy timeout, case failure, malformed billing, and Gemini failure.
7. Inspect request traces and verify metrics change after real executions.
8. Review source, architecture, security, deployment, and handover evidence.
9. Record each material deduction with requirement, observed result, expected result, evidence, and reason.
