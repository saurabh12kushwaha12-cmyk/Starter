## Automated evidence command

```bash
python3 -m py_compile starter-solution/server.py mock-services/server.py
python3 -m unittest discover -s starter-solution/tests -v
```

GitHub Actions performs these checks on supported pushes and pull requests under Python 3.11 and 3.12. It validates the supplied challenge scenario JSON and failure paths in a synthetic test environment. A successful CI run is automated test evidence, not evidence of a successful real Gemini API call, an actual cloud deployment, or a recorded demo.
