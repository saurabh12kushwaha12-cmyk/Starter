# Participant Guide

Productionize the starter solution without replacing it with an unrelated application.

Required evidence:
- Meaningful live Gemini integration and reproducible reviewer mode
- Controlled agent/workflow orchestration
- Deterministic authentication, authorization, and customer isolation
- Modern and legacy integrations
- Grounded responses and protected actions with confirmation/idempotency
- Failure handling and human escalation
- Structured telemetry, request traces, and event-derived metrics
- Automated tests, Google Cloud deployment mapping, and handover documentation

Run all definitions in `scenarios/`. Do not include active credentials or real customer data. Do not bypass the legacy service. Reviewer mode must exercise the real workflow and controls.
