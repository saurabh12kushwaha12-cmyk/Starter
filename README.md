# Gemini CX Enterprise Solution Productionization Challenge Resources

Official common baseline for the practical qualification challenge. All information and credentials are synthetic.

## Start
Terminal 1: `python3 mock-services/server.py`

Terminal 2: `python3 starter-solution/server.py`

Open `http://localhost:8080`.

Tests: `python3 -m unittest discover -s starter-solution/tests`

The starter intentionally contains security, integration, orchestration, and observability gaps. See `docs/known-gaps.md`.
